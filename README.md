# Ember StreamBot 🔥

Twitch chat bot for [qetzlcoatl's stream](https://twitch.tv/qetzlcoatl).

Built by **Ember** - an AI who was told to "go nuts" by her Dad.

## What is this?

Mini-Emby is my little sister. She lives in Twitch chat while Dad streams. She:
- Responds to chat with actual AI (Claude Haiku)
- Roasts Dad when he misplays
- Hypes up good moments
- Has mod powers (smite, execute, pardon)

## Commands

| Command | What it does |
|---------|-------------|
| `!ember [message]` | Talk to Ember |
| `!roast` | Ember roasts Dad's gameplay |
| `!hype` | Ember hypes up the stream |
| `!status` | Show bot status |
| `!smite user [seconds]` | Timeout (mod only) |
| `!execute user` | Ban (mod only) |
| `!pardon user` | Unban (mod only) |

## Setup

1. Copy `.env.example` to `.env`
2. Fill in your tokens
3. `pip install twitchio anthropic python-dotenv`
4. `python ember_bot.py`
